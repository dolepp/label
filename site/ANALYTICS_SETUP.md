# Аналитика и ссылки на площадки

В админке откройте **Метрики** и укажите ID Яндекс Метрики, Google Analytics 4,
VK Реклама и/или Meta Pixel. Пустое поле отключает соответствующий сервис.
Можно также задать ANALYTICS_YANDEX_ID, ANALYTICS_GOOGLE_ID, ANALYTICS_VK_ID,
ANALYTICS_META_ID в окружении до первого сохранения настроек в админке.
Это публичные идентификаторы счётчиков, а не OAuth client ID и не секретные токены.
Сами аккаунты и счётчики создаются в кабинетах соответствующих сервисов.

Необходимые cookie включены всегда. Скрипты аналитики запускаются только после
согласия на аналитику; рекламные пиксели — после отдельного выбора рекламы.
Настройки доступны внизу страницы, отказ перезагружает страницу и удаляет доступные
первичные cookie счётчиков. Webvisor, автоматическое сопоставление контактов и
Google Signals не подключаются. В разрешённых событиях нет полей форм, текстов
песен, паспортов, email, балансов, кодов входа и полных адресов с query-параметрами.
Переходы по разделам учитываются как просмотры SPA. События собственной статистики
не связываются с аккаунтами и удаляются после 90 дней; сводка показывает 30 дней.
Подключение реальных сервисов требует указать их ID. Без ID работает только
собственная статистика посетителей, разрешивших аналитику.

В карточке релиза нажмите **Ссылка на все площадки**. Укажите адрес, ссылки и
галочку публикации. Уже сохранённые в релизе ссылки распознаются по домену площадки.
Поиск конкретного трека на площадках не выполняется: страницы создаются из
предоставленных ссылок. Редактирование доступно владельцу релиза, публично видны
только название, артист, обложка, дата и кнопки прослушивания. Снять публикацию
можно в том же окне. Статистика переходов учитывает посетителей с разрешённой
аналитикой и показывает количество действий, не уникальных людей.

SMARTLINK_PUBLIC_BASE по умолчанию — https://twaslabel.ru. Ссылки вида /l/slug
работают через отдельную страницу /listen/ на GitHub Pages и напрямую через
Flask. Обложки и данные загружаются из публичного API без раскрытия владельца
или приватных аудиофайлов. Предпросмотр обложки в социальных сетях на статическом
GitHub Pages не гарантирован, потому что метаданные загружаются JavaScript.

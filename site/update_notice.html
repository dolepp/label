⚠️ Требуется обновление страницы

Проблема: Ваш браузер использует устаревшую версию сайта из кеша.

🔧 Решение - выберите один из способов:

1. БЫСТРЫЙ СПОСОБ (рекомендуется):
Нажмите одновременно: Ctrl + Shift + R (Windows/Linux)
Или: Cmd + Shift + R (Mac)
2. Для Chrome/Edge/Firefox:
1. Нажмите F12 (откроется консоль разработчика)
2. Правой кнопкой мыши на кнопку обновления в браузере
3. Выберите "Очистить кеш и жестко перезагрузить"
4. Закройте консоль F12
3. Полная очистка кеша:
• Chrome: Настройки → Конфиденциальность → Очистить данные → "Изображения и файлы" → Очистить
• Firefox: Настройки → Приватность → Очистить данные → "Кеш" → Очистить
• Edge: Настройки → Конфиденциальность → Очистить данные → "Кешированные данные" → Очистить

✅ После очистки кеша:

Вернитесь на главную страницу и попробуйте создать дистрибуцию EP снова.

🏠 Вернуться на главную

🔍 Как проверить, что загружена новая версия:

1. Откройте консоль браузера (F12)
2. Перейдите на вкладку "Console"
3. При выборе EP/ALBUM/Maxi Single вы должны увидеть переход на шаг "track-count"
4. POST запрос должен идти на /api/albums/create, а не /api/distribution/create
